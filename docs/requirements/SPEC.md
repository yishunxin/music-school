# 琴行课时管理系统 - 需求规格文档

## 1. 项目概述

### 1.1 项目背景

一款面向琴行/音乐培训机构的课时管理系统，支持学生多课程管理、课时充值签到、教师工资结算等功能。

### 1.2 项目目标

- 提供简洁高效的学生课时管理
- 自动化教师工资计算与结算
- 实现财务收支的透明化管理

### 1.3 目标用户

- 琴行/培训机构管理员
- 前台接待人员
- 财务人员

## 2. 功能需求

### 2.1 账号管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 账号列表 | 查看所有管理员账号 | P1 |
| 添加账号 | 新增管理员账号 | P1 |
| 编辑账号 | 修改账号信息 | P1 |
| 删除账号 | 删除管理员账号 | P1 |
| 修改密码 | 修改当前账号密码 | P1 |

### 2.2 教师管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 教师列表 | 查看所有教师信息 | P1 |
| 添加教师 | 新增教师信息（姓名、科目、联系电话） | P1 |
| 编辑教师 | 修改教师信息 | P1 |
| 删除教师 | 删除教师信息 | P1 |
| 课程关联 | 关联教师可教授的课程类型 | P1 |

### 2.3 课程类型管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 课程列表 | 查看所有课程类型 | P1 |
| 添加课程 | 新增课程类型（乐器类型+级数） | P1 |
| 编辑课程 | 修改课程信息 | P1 |
| 删除课程 | 删除课程类型 | P1 |
| 课时配置 | 设置单节课时长和单价 | P1 |

**示例**：
- 钢琴(1级)、钢琴(5级)
- 吉他(入门)、吉他(考级)
- 古筝(基础)、古筝(提高)

### 2.4 学生管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 学生列表 | 查看所有学生信息 | P1 |
| 添加学生 | 新增学生（姓名、性别、年龄、联系方式） | P1 |
| 编辑学生 | 修改学生信息 | P1 |
| 删除学生 | 删除学生（需验证密码） | P1 |
| 课时查看 | 查看学生各课程的剩余课时 | P1 |
| 课时提醒 | 首页显示课时不足的学生（剩余≤1） | P2 |

### 2.5 课时管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 课时充值 | 选择学生、课程类型、授课老师，填写购买/赠送课时 | P1 |
| 课时签到 | 选择学生后选择上哪门课（默认充值最早的课程） | P1 |
| 课时退课 | 退还未消耗的课时 | P2 |
| 充值记录 | 查看充值历史记录 | P1 |
| 上课记录 | 查看上课签到历史 | P1 |

**业务规则**：
- 总课时 = 购买课时 + 赠送课时
- 签到时默认消耗 1 课时
- 签到时间默认当前时间

### 2.6 财务管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 收支记录 | 记录收入/支出明细 | P1 |
| 收入统计 | 按时间/类型统计收入 | P1 |
| 支出统计 | 按时间/类型统计支出 | P1 |
| 报表导出 | 导出财务报表 | P2 |

**收支分类**：
- 收入：课时充值收入
- 支出：教师课酬支出

### 2.7 工资管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 工资生成 | 按月生成教师工资单 | P1 |
| 工资明细 | 查看教师工资构成（按课程类型统计） | P1 |
| 发放状态 | 跟踪工资发放状态 | P1 |
| 月度汇总 | 汇总当月所有教师工资 | P1 |

**工资计算规则**：
- 教师课酬 = 总费用 ÷ 购买课时 ÷ 2（每次上课时计算）
- 月结工资 = 该教师当月所有支出记录求和

## 3. 非功能需求

### 3.1 性能要求

- 页面响应时间 < 2秒
- 支持 1000+ 学生数据
- 支持 100+ 教师数据

### 3.2 安全要求

- JWT 令牌认证
- 密码加密存储
- 删除操作需二次确认

### 3.3 可用性要求

- 支持桌面端（侧边栏导航）
- 支持移动端（底部Tab导航）
- 数据定时备份（每天0点，保留7天）

### 3.4 技术约束

- 前端：React 18 + Vite + Tailwind CSS
- 后端：Node.js + Express
- 数据库：MySQL/MariaDB

## 4. 数据模型

### 4.1 ER 图

```
┌─────────────┐     ┌─────────────────┐     ┌──────────────┐
│   teachers  │────<│  course_types   │     │    users     │
└─────────────┘     └─────────────────┘     └──────────────┘
       │                    │                      │
       │                    │                      │
       ▼                    ▼                      ▼
┌─────────────┐     ┌─────────────────┐     ┌──────────────┐
│   students  │────<│   recharges     │>────│transactions │
└─────────────┘     └─────────────────┘     └──────────────┘
       │                    │
       │                    │
       ▼                    ▼
┌─────────────┐     ┌─────────────────┐
│ course_logs │     │ teacher_salary  │
└─────────────┘     └─────────────────┘
```

### 4.2 核心关系

- **一个学生** 可有 **多条充值记录**（多门课程）
- **一条充值记录** 对应 **一个教师** 和 **一个课程类型**
- **一次签到** 对应 **一条充值记录**
- **教师工资** 由 **多次上课支出** 汇总
